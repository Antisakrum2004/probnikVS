# Метаданные расширения 1С

## Конфигурация расширения
- **Имя:** Видеоконсультации_EmAI
- **Тип:** Расширение конфигурации (.cfe)
- **Безопасный режим:** Нет (нужен HTTP-запросы)
- **Изменение конфигурации:** Расширяем формы существующих объектов

---

### 2. Документ «Запись на приём» (расширение формы)

**Добавляемые реквизиты формы (НЕ реквизиты объекта):**
| Имя | Синоним | Тип данных | Примечание |
|-----|---------|-----------|------------|
| Видеоконсультация | Видеоконсультация | Булево | Галка на форме |
| СтатусСEmAI | Статус с EmAI | Строка(200) | Только для чтения |

**Добавляемые команды формы:**
| Имя | Синоним | Действие |
|-----|---------|----------|
| ОтправитьВEmAI | Отправить в EmAI | &НаКлиенте → HTTP POST → middleware → EmAI |

**Логика при проведении (подписка на событие ОбработкаПроведения):**
- Если Видеоконсультация = Истина и СтатусСEmAI содержит «успешно»:
  - Создать запись в РС «УчетВидеоконсультаций»
  - ПриемЗапланирован = Истина
- Если заявка отклонена (ошибка от EmAI):
  - Отказ = Истина
  - Сообщить пользователю причину

### 3. Документ «Отмена записи на приём» (расширение формы)

**Добавляемые команды формы:**
| Имя | Синоним | Действие |
|-----|---------|----------|
| ОтправитьОтменуВEmAI | Отправить в EmAI | HTTP POST → conference/event → action: CANCEL |

**Логика:**
- Найти запись в РС по sessionID
- Отправить запрос отмены
- При успехе: ПриемЗапланирован = Ложь

### 4. Обработка «Видеоконсультация» (АРМ Врача)

**Тип:** Внешняя обработка или обработка в расширении

**Реквизиты формы:**
| Имя | Синоним | Тип данных |
|-----|---------|-----------|
| Врач | Врач | СправочникСсылка.Сотрудники |
| Пациент | Пациент | СправочникСсылка.ФизическиеЛица |
| ТекущаяСсылка | Ссылка на консультацию | Строка(500) | Скрытое |

**Команды формы:**
| Имя | Синоним | Действие |
|-----|---------|----------|
| НачатьВидеоконсультацию | Начать видеоконсультацию | Поиск в РС → открытие ссылки в браузере |
| ЗавершитьКонсультацию | Завершить консультацию | HTTP POST → conference/event → action: COMPLETE |

**Логика «Начать»:**
1. Найти запись в РС по Врачу, Пациенту, ПриемЗапланирован = Истина
2. Получить СсылкаНаВидеоконсультацию
3. Открыть в системном браузере через `ЗапуститьПриложение()`

**Логика «Завершить»:**
1. Найти запись в РС
2. Отправить COMPLETE в EmAI
3. При успехе: ПриемПроведен = Истина, ПриемЗапланирован = Ложь
