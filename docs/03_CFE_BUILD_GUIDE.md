# Руководство по сборке расширения (.cfe)

## Шаг 1. Создание расширения в Конфигураторе

1. Открыть конфигуратор МИС
2. **Администрирование → Расширения конфигурации**
3. Нажать **«Добавить»**
4. Заполнить:
   - **Имя:** `Видеоконсультации_EmAI`
   - **Синоним:** `Видеоконсультации EmAI`
   - **Безопасный режим:** ❌ (снять галку — нужны HTTP-запросы)
   - **Изменение конфигурации:** ✅ (ставим галку)

## Шаг 2. Создание объекта «Регистр сведений»

1. В дереве расширения → **Регистры сведений**
2. Правая кнопка → **Создать**
3. Установить:
   - **Имя:** `УчетВидеоконсультаций`
   - **Синоним:** `Учет видеоконсультаций`
   - **Подсистема:** (выбрать или создать «Видеоконсультации»)
4. На вкладке **Основные:**
   - **Периодичность:** Непериодический
   - **Режим записи:** Независимый
5. На вкладке **Измерения:** добавить (таблица см. `docs/02_EXTENSION_METADATA.md`):
   - ИдентификаторСессии (Строка(50))
   - КодПациента (Строка(50))
   - ФИОПациента (Строка(200))
   - КодСотрудника (Строка(50))
   - ФИОВрача (Строка(200))
   - Ставка (СправочникСсылка.ДолжностныеСтавки)
6. На вкладке **Ресурсы:** добавить:
   - ТипКонсультации (Строка(20))
   - ДатаВремяКонсультации (ДатаВремя)
   - ИдентификаторEmAI (Число(15,0))
   - СсылкаНаВидеоконсультацию (Строка(500))
   - ПриемЗапланирован (Булево)
   - ПриемПроведен (Булево)

## Шаг 3. Общие модули

1. **Общие → Общие модули** → Создать:
   - `ВидеоконсультацииСервер`
     - **Сервер:** ✅ (галка)
     - **Вызов сервера:** ❌
     - **Клиент:** ❌
     - Вставить код из `src/1c-extension/ВидеоконсультацииСервер.bsl`
   
   - `ВидеоконсультацииВызовСервера`
     - **Сервер:** ❌
     - **Вызов сервера:** ✅
     - **Клиент:** ✅
     - **Сервер (вызов сервера):** ✅
     - Вставить код из `src/1c-extension/ВидеоконсультацииВызовСервера.bsl`

## Шаг 4. Расширение формы «Запись на приём»

1. В дереве расширения → **Формы** → **Правая кнопка** → **Добавить**
2. Тип: **Расширение формы существующего объекта**
3. Выбрать: **Документ.ЗаписьНаПрием** (уточнить имя объекта в вашей конфигурации)
4. В модуле формы вставить код из `src/1c-extension/ФормаЗаписьНаПрием.bsl`
5. На форме (в визуальном редакторе):
   - Добавить реквизит `Расш1_Видеоконсультация` (Булево)
   - Добавить реквизит `Расш1_EmaiSessionID` (Число)
   - Добавить реквизит `Расш1_СсылкаВК` (Строка)
   - Добавить элемент: Переключатель «Видеоконсультация»
   - Добавить элемент: Поле «Статус с EmAI» (только чтение)
   - Добавить элемент: Кнопка «Отправить в EmAI» → обработчик `Расш1_ОтправитьВEmAI`
6. **Подписка на событие проведения:**
   - В дереве расширения → **Подписки на события**
   - Создать подписку на `Документ.ЗаписьНаПрием.ОбработкаПроведения`
   - Привязать к `Расш1_ОбработкаПроведения`

## Шаг 5. Расширение формы «Отмена записи на приём»

1. Аналогично Шагу 4
2. Выбрать документ **Отмена записи на приём**
3. Код: `src/1c-extension/ФормаОтменаЗаписи.bsl`
4. Добавить элементы: Кнопка «Отправить отмену в EmAI», Поле «Статус отмены»

## Шаг 6. Обработка «Видеоконсультация»

1. В дереве расширения → **Обработки** → Создать:
   - **Имя:** `Видеоконсультация`
   - **Синоним:** `Видеоконсультация`
2. Создать форму:
   - Реквизит `Врач` (СправочникСсылка.Сотрудники)
   - Реквизит `Пациент` (СправочникСсылка.ФизическиеЛица)
   - Реквизит `Расш1_SessionID` (Строка, скрытый)
   - Реквизит `Расш1_EmaiSessionID` (Число, скрытый)
3. Код формы: `src/1c-extension/ФормаВидеоконсультация.bsl`
4. Элементы:
   - Поле выбора «Врач»
   - Поле выбора «Пациент»
   - Кнопка «Начать видеоконсультацию»
   - Кнопка «Завершить консультацию» (изначально недоступна)

## Шаг 7. Адаптация кода под вашу конфигурацию

### ВАЖНО: замена имён объектов

В коде используются предположительные имена объектов. Вам нужно заменить их на реальные:

| Предположительное имя | Что заменить на | Где искать |
|---|---|---|
| `Объект.Пациент` | Реальное имя реквизита пациента | Форма «Запись на приём» |
| `Объект.Специалист` | Реальное имя реквизита врача | Форма «Запись на приём» |
| `Объект.ДатаНачала` | Реальное имя реквизита даты | Форма «Запись на приём» |
| `Объект.ДолжностнаяСтавка` | Реальное имя реквизита ставки | Форма «Запись на приём» |
| `Справочник.ДолжностныеСтавки` | Реальное имя справочника | Метаданные конфигурации |
| `Документ.ЗаписьНаПрием` | Реальное имя документа | Метаданные конфигурации |

## Шаг 8. Конфигурация настроек подключения

В файле `ВидеоконсультацииСервер.bsl` есть функция `ПолучитьНастройкиПодключения()`.

**Рекомендация:** вынести URL middleware в константу расширения:

1. **Константы** → Создать:
   - `URLMiddleware` (Строка(200)) — `http://msi-2.dialog.ip:58080`
2. В функции `ПолучитьНастройкиПодключения()` заменить:
   ```
   Результат.Вставить("URLMiddleware", Константы.URLMiddleware.Получить());
   ```

## Шаг 9. Тестирование

1. Запустить 1С в режиме отладки
2. Открыть обработку «Видеоконсультация»
3. Создать «Запись на приём» с галкой «Видеоконсультация»
4. Нажать «Отправить в EmAI» — проверить, что статус обновился
5. Провести документ — проверить запись в регистре
6. В обработке выбрать врача и пациента → «Начать» — браузер откроется
7. «Завершить» — проверить флаг «Прием проведен»

## Шаг 10. Экспорт расширения

1. **Администрирование → Расширения конфигурации**
2. Выбрать `Видеоконсультации_EmAI`
3. Нажать **«Экспорт»** → сохранить как `Видеоконсультации_EmAI.cfe`

## Установка на рабочую базу

1. **Администрирование → Расширения конфигурации**
2. Нажать **«Импорт»** → выбрать .cfe-файл
3. Установить/обновить расширение
4. **Обновление конфигурации базы данных** (F7)
